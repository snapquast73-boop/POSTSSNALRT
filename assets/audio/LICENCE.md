# Alert-sound licence record

No recording is currently installed in this directory. The site plays the
synthesized cha-ching fallback (see [`README.md`](README.md) and
[`docs/alert-sound.md`](../../docs/alert-sound.md)).

When a recording is installed, fill in this file **before committing it**:

| Field | Value |
| --- | --- |
| File | `cha-ching.<ext>` (mp3 / wav / ogg / m4a) |
| Title | _(unverified — fill in on install)_ |
| Author | _(unverified — fill in on install)_ |
| Source URL | _(unverified — fill in on install)_ |
| Licence | _(unverified — fill in on install)_ |
| Installed on | _(unverified — fill in on install)_ |

Do not commit a recording whose licence does not permit redistribution in a
public repository.
