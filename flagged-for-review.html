F-11 Runs at Risk is attribution, not prediction. The flag is set only when the official payload credits a scoring movement to the reviewed event (runners[].details.isScoringEvent / playIndex); the payload never says what replay actually removed, so a review that has already been resolved on such a play still shows the flag, and a review of a play with no run credited never does. Re-evaluated on every poll for every tracked review (previously only for a brand-new row), decoupled from the game's "under review" status for the flag itself; the desktop notification stays limited to an active review on the reviewed play.
